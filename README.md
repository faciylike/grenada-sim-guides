## ｜快速上手：APN设置与设备兼容性

　　买到卡，别急着插卡狂欢。很多手机不会自动配置网络，需要手动设置APN（接入点名称）。这个步骤卡住了不少人。

- **Digicel** 的APN通常是：`digicelgrenada`
- **Flow** 的APN通常是：`flowgrenada`

　　（如果不行，试试全部小写。话说回来，运营商店员通常会给你一张小纸条，上面写着这些信息，记得索取！）

　　插上卡，重启手机，在设置里找到“移动网络”-“接入点名称（APN）”，新建一个并输入对应信息即可。安卓和iOS的位置略有不同，但耐心找找都能发现。有没有遇到过重启后还是只有信号格没有“4G”标志的情况？十有八九是APN在作祟。

　　至于设备，现在的手机基本都支持全频段了。但如果你用的是非常老旧的机型，最好查一下是否支持当地的3G（BAND 1/8）和4G（BAND 2/4/7/28）频段。否则，你可能只能打个电话，上网就慢如蜗牛了。
